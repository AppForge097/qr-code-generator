# QR Code Generator

A small Python utility that turns text or links into downloadable QR code images.

## Features

- Generate QR codes from text and URLs
- Save generated codes as PNG images
- Straightforward code that is easy to customize

## Requirements

- Python 3
- `qrcode[pil]`

Install the dependency:

```bash
pip install "qrcode[pil]"
```

## Run

```bash
python qr_generator.py
```

## Tech stack

Python · qrcode · Pillow
