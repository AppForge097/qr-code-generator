# QR Code Generator

A simple Python utility for generating QR codes.

## Features

- Generate QR codes from text or links
- Save generated codes as PNG images
- Small and easy to customize

## Run

Install the required package:

```bash
pip install qrcode[pil]
```

Then run:

```bash
python qr_generator.py
```

## Tech Stack

- Python
- qrcode
- Pillow
